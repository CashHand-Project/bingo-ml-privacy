# Política de Privacidade — Bingo ML

*Última atualização: 16/05/2026*

O aplicativo **Bingo ML - Contagem de Pacotes** não coleta, armazena, transmite nem compartilha nenhum dado pessoal do usuário.

Todos os dados gerados pelo app (contagem de pacotes e paradas) existem apenas na memória do dispositivo durante o uso e são descartados ao fechar o aplicativo.

## Anúncios

Este app exibe anúncios via Google AdMob. O Google pode coletar dados para personalização de anúncios de acordo com sua própria política de privacidade: https://policies.google.com/privacy
